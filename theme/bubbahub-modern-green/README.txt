BubbaHub Modern Green

WordPress block theme for the Bubba Hub Directory.

IMPORTANT: The installable theme package must contain this folder's style.css at the ROOT of the theme folder, alongside theme.json and functions.php.

For a ZIP upload in WordPress, zip the contents of the `theme/bubbahub-modern-green` folder so the ZIP contains:
- style.css
- theme.json
- functions.php
- templates/
- parts/
- assets/ (if present)

Do not create a ZIP whose top level is `theme/bubbahub-modern-green/theme/bubbahub-modern-green/`.
